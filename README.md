# AbleSpace QA Assessment

## Overview

This repository contains my QA assessment for AbleSpace, focusing on manual testing of Student Management and related application features.

## Contents

- **AbleSpace_QA_Assessment.pdf** — Test cases, testing summary, and issues identified during testing.
- **Evidence Videos** — Video recordings demonstrating the observed issues.

## Testing Scope

The assessment covers the following areas:

- Signup and Login
- Student Management and student forms
- Caseload roster
- Groups and group membership
- Service Time
- Family Center
- Refer & Earn
- Data validation and data consistency
- UI behaviour and responsive layout

## Testing Approach

Testing was performed manually using defined test steps, expected results, and actual results. Observed issues were documented with reproduction steps, priority levels, and supporting evidence where available.

## Testing Environment

- **Application:** AbleSpace Staging
- **Browsers:** Google Chrome and Firefox
- **Testing Type:** Manual functional and UI testing
- **Viewports:** Desktop, mobile emulation, and tablet sizes

## Notes

The documented issues reflect the behaviour observed during testing. Their technical root causes have not necessarily been confirmed and may require further investigation.
